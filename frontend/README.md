# BungeLens AI — Frontend

This repository contains the frontend for BungeLens AI. It was originally created with Next.js and has been migrated to a Vite + React setup.

## Development

Install dependencies and run the dev server from the `frontend` directory:

```bash
cd frontend
# Use pnpm (recommended) or npm
pnpm install --no-frozen-lockfile
pnpm dev

# or with npm
npm install
npm run dev
```

The app should be available at `http://localhost:5173` when the Vite server is running.
